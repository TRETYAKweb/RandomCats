# Деплой на GitHub Pages

Сайт: https://tretyakweb.github.io/RandomCats/

1. **Закоммить изменения.** Выполни `git status` и `git diff`.
   - Если изменений нет — переходи к шагу 2.
   - Если среди изменений есть мусор или секреты (`.DS_Store`, `.env`, ключи, токены, логи) — не коммить их, скажи об этом пользователю.
   - Остальное добавь через `git add <файлы>` (по именам, не `git add .`) и закоммить.
   - Сообщение коммита — в стиле истории репозитория (посмотри `git log --oneline -10`): conventional commits с gitmoji, например `feat(js): :sparkles: add coin animation`.
2. **Сделай git push.** Выполни `git push origin main`. Если push упал — покажи ошибку и остановись.
3. **Проверь, что сайт открывается.** GitHub Pages обновляется не сразу, подожди около минуты, затем выполни `curl -s -o /dev/null -w "%{http_code}" https://tretyakweb.github.io/RandomCats/`. Код `200` — всё ок. Иначе сообщи пользователю код ответа.
4. **Отчитайся.** Коротко: что закоммичено (хеш и сообщение), запушено ли, какой код ответа у сайта.
